## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser → static product entry | An arbitrary direct request must resolve only to generated public content. |
| Product page → external native destinations | Browser navigation leaves ZERO-PAPER HUB for WhatsApp, protocols, or HAOO onboarding. |
| Compile-time product data → href attributes | Fixed strings become navigable URLs and must not include visitor data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-03 | Spoofing | assisted/self-onboarding links | high | mitigate | Central exact HTTPS/protocol constants, visible destination labels, same-tab navigation, and href contract tests. |
| T-01-04 | Tampering | WhatsApp URL construction | medium | mitigate | Fixed digits-only destination, compile-time generic text, deterministic encoding, decoded-equality test, and no user/page input. |
