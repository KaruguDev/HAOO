<objective>
Finish what the tracer deliberately left: every remaining literal in the HAOO repository that names
the retired location, and the two pieces of repository hygiene the split exposes.

Two kinds of literal, and they are not the same kind of change. The form source line is a *statement
to a human* — it appears in the email a prospect's enquiry produces, and after the move it names a
page that no longer serves HAOO. The jsdom fixture origins are *test scaffolding* — they set the
simulated page location that the campaign normalizer, the bounded-context reader and the capture
contract read. Both must move; only the first is visitor-facing.

Purpose: an enquiry that lands in the inbox says where it truly came from, and no HAOO-owned file
names a host it no longer lives on.
Output: thirteen literals re-pointed, a README that describes its own repository, and an ignore rule
that closes a pre-existing gap.
</objective>
