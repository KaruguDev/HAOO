## Accomplishments

The form source line now reads `Sent from the HAOO product page on ZERO-PAPER HUB
(www.haoo.online)`. It keeps the parent-company name, which D-07 preserves and which is true on
any domain, and changes only the URL — the part that had stopped being true when the page moved.
Its two byte-exact mirrors moved with it.

Thirteen simulated page origins were re-pointed off the retired nested path. Three `replaceState`
path expectations moved in lockstep, not as a stylistic choice: the campaign normalizer replaces
history state with `${url.pathname}${url.search}${url.hash}`, so re-pointing an origin to the site
root forces the expected pathname to the root as well. Leaving them would have failed.

The README was reduced to the repository it actually sits in, and both build-probe directories are
now ignored.
