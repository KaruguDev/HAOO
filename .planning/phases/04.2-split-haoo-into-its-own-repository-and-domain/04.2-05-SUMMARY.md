## Accomplishments

The measurement project answers for two properties, because D-11 deliberately kept them in one
project. That made every unscoped query a sum across both, so a report heading naming HAOO promised
a scope its number did not have. Every query is now bounded at `HAOO_DOMAIN_CUTOVER_DAY`, the header
states that day, and the caveat block explains it.

`cutoverDay` was added as a **required** member of `ReportModel` rather than an optional one with a
default. A model that omitted it would render a plausible-looking document whose numbers quietly
disagreed with its headings — the failure mode this plan exists to remove — so omission is a
typecheck error instead.
