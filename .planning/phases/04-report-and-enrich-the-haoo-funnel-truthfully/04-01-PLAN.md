<objective>
Deliver the owner-facing HAOO funnel report end-to-end: a real Plausible Stats API v2 query,
fail-closed validation of the untrusted response, a closed event-to-stage/label dictionary, and a
self-contained HTML document written atomically to a gitignored local path.

times each recorded HAOO action happened in a period, **so that** I can understand aggregate HAOO
interest without a dashboard that implies people moved through a funnel.

browser evidence literally. This plan proves the whole path works before the document is fully
dressed (04-03) and before live collection is enabled (04-05).

`src/test/haoo-report.test.ts` contract suite, an npm script, and a gitignored report path.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Plausible Stats API -> local generator process | Untrusted JSON crosses here; the provider controls goal names, row count, and count values. |
| local process environment -> generator | The bearer key crosses here; it must never cross onward into the rendered document, stdout, or stderr. |
| generator -> local filesystem | The rendered document crosses here; a partial write would produce a report claiming more periods than it holds. |
