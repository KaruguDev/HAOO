<objective>
Make the visitor-facing disclosure true again. Phase 3 shipped a notice promising that no engagement
summary is attached; plan 04-02 makes that promise false, so this plan replaces it with the
owner-approved description of exactly what is now attached, and adds the labelled disclosure group
that lists it.

**As a HAOO visitor**, **I want to** read before I submit exactly what context travels with my
enquiry, **so that** nothing about my browser reaches the product owner that I was not told about.

Purpose: MEAS-05 requires the summary to be *disclosed*, not merely attached. MEAS-08 requires the
disclosure to describe browser-observable facts. Phase 2 set the precedent that byte-exact
visitor-facing notices are approved by a human before they ship.
Output: the replaced collection-notice clause in every place it is asserted, the new disclosure
summary group, and the contracts that pin both.
</objective>
