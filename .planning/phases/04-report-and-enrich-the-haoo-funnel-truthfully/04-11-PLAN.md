<objective>
Close gap 1 of `04-VERIFICATION.md`: restore the POSIX directory-extraction behaviour that 04-10 regressed, make the separator set a property of the destination's shape instead of an unconditional pair, extend the bare-root guard to UNC roots, and pin every probed destination shape in the contract table that was supposed to make this contract safe to change.

Purpose: 04-10 fixed the Windows half of first-run directory creation by searching for both separators unconditionally. On POSIX a backslash is a legal filename character, so `generateHaooReport` now extracts the wrong parent for a destination whose final segment contains one and hands that wrong parent to a recursive `mkdirSync`, creating a directory nothing removes. The declared truth's clause "the existing POSIX behaviour is unchanged" is observably false, and the five-row table added to pin the contract does not contain the shape that broke.
Output: a `directoryOf` whose separator set is chosen from the destination, a bare-root guard that covers UNC as well as drive roots, and a contract table that carries the regressed shapes so this cannot recur invisibly.

This is a complete vertical fix for one gap: the parsing change, the behavioural coverage that pins it, and the docstring that describes the rule all ship in this plan. No layer of it is deferred to another plan.
</objective>
