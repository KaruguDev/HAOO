<objective>
Close verification gap 1 and review finding CR-01: make the configured analytics script source provable against an independently trusted approved origin/path contract, so a tampered public build variable can no longer load attacker-controlled first-party JavaScript.

Purpose: MEAS-01 requires that aggregate collection can be safely enabled, and MEAS-08 requires that the evidence the report describes comes from the measurement layer this project actually controls. `resolvePlausibleScriptSrc` currently accepts any structurally valid HTTPS `.js` URL, so a changed deployment variable can execute arbitrary code with page, form, and storage access. That contradicts the phase's no-identity-tracking outcome and threat T-04-19.
Output: a repository-owned approved-source contract, a build-time constant that carries it only into a deliberately configured build, an origin-and-path-constrained resolver, adversarial rejection tests, a bundle-import invariant, and owner documentation of the constraint.
</objective>
