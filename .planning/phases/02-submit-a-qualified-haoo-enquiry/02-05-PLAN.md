## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fetch promise -> terminal UI | An external provider's status or network failure determines visible success/failure state. |
| retained form state -> retry request | Previously entered personal data is resubmitted only after explicit visitor activation. |
| static noscript markup -> visitor | Recovery links must remain exact without React or runtime validation. |
