<objective>
Prove QUAL-02's form half: every state the qualification form can reach announces itself, keeps focus
somewhere a visitor can find, and keeps the visitor's work.

All the interesting states — in-flight, success, transport failure, blocked — cannot be exercised
against live production without either sending real mail or lying to a real endpoint. They are
exercised here on the local preview mirror by routing the endpoint, which is precisely why the local
target exists as a first-class project rather than as an afterthought.

Purpose: convert the shipped form's error, recovery and announcement behaviour from designed to
measured.
Output: `e2e/form-states.e2e.ts` and `05-EVIDENCE-FORM-STATES.md`.

**Working directory: the HAOO checkout** (05-01, D-01/D-04).
</objective>

## Backstop item carried into `must_haves` (not silently dropped)

- **Long option labels in the qualification selects at the narrowest width.** The five closed option
  lists include long county and banded-portfolio labels with dashes. A native select clips rather than
  reflows, and the per-element viewport sweep cannot see inside an open native popup. This is held out
  as a **backstop** item in `must_haves.truths`: it is a visual judgement no assertion settles cleanly,
  it is not asserted mechanically here, and at verification time it routes to human judgement rather
  than passing silently. Task 3 captures the rendered control widths and the longest label per list as
  measured inputs to that judgement.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| harness → the qualification endpoint | Routing the endpoint on the preview target is the mechanism that keeps failure testing away from a real mailbox |
| serialised request body → the visitor's later edits | Once serialised, a correction the visitor makes is not in the request; the disabled-control contract is what prevents a silently discarded edit |
| browser confirmation → a delivery claim | The page can only report acceptance; treating that as delivery would overclaim |
