## Planner assumptions carried forward (unresolved probe edges — surfaced, not dropped)

- **LEAD-07 / concurrency — "If interrupted or run in parallel, what is guaranteed?" (unresolved).**
  Third and final restatement, at the point it matters most. Nothing mechanically serialises this
  send. The guarantees are procedural and are made *visible* rather than enforced: the marker is
  recorded before the send, exactly one send is performed, the count of messages sent is recorded as
  an integer, and every link carries its own timestamp. If this plan were interrupted between the send
  and the owner's mailbox check, the chain is **not resumed from the recorded marker** — the marker is
  still valid for searching, but link 3's status stays open until a human reads the mailbox. If a send
  is retried, the record states how many messages now exist and which marker each carries; it never
  silently reports the last one.

- **Assumption A6 (from research), now load-bearing.** Activation is assumed to be permanent and not
  bound per submitting origin. If this send fails despite a confirmed activation, that assumption is
  what broke, and the two-record structure is what makes that legible.
