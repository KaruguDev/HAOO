<objective>
**TRACER.** Install the browser-based evidence instrument into a repository that has never had one,
and prove the whole path end to end on one thin slice: a real Chromium loads the live
`https://www.haoo.online/`, an axe run executes against it, a per-element overflow sweep measures one
viewport, and the measured values land in a committed evidence artifact — with the harness itself
inside `npm run typecheck` and outside `npm test`.

This is deliberately the first thing built. Almost every remaining plan in the phase is an expansion
of this slice, and three of the five things that can go structurally wrong (the axe rule-composition
question, the typecheck escape, the Vitest glob collision) are only observable once a real run
exists. Discovering any of them at the finish line would leave no room to act.

Purpose: prove the architecture of the evidence instrument before nine specs are written on top of it.
Output: a runnable `npm run test:e2e` / `npm run test:e2e:live`, and `05-EVIDENCE-HARNESS.md` recording
what the first live run measured.

**Working directory: the HAOO checkout** (05-01, D-01/D-04). Nothing in this plan is installed in
`../ZERO-PAPERHUB` — D-08 keeps SPLT-01 clean and adds no entry to the ratified 26-path
`shared-scaffold.txt` allowlist.
</objective>
