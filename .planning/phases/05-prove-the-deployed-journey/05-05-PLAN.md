<objective>
Build the shared substrate every remaining evidence spec sits on: four closed lists, one axe builder
factory, one measured-value recorder, and the two overflow measurement helpers. Then re-express the
tracer through them, so the fixture layer is proven to carry the tracer's behaviour rather than
merely intended to.

Every list here follows the house closed-list discipline the existing focus-contrast suite
established: `as const`, a doc-comment stating how an entry is admitted, a reason per entry, and a
vacuity guard that fails when a listed entry yields nothing. That guard is what keeps this phase's
green marks from being green about nothing.

Purpose: nine specs are about to be written. Declaring the subjects once, with reasons, is what stops
them drifting apart.
Output: `e2e/fixtures/` and a tracer that consumes it unchanged in behaviour.

**Working directory: the HAOO checkout** (05-01, D-01/D-04).
</objective>

    **`e2e/fixtures/overflow.ts`** — export two helpers, both taking a Playwright `Page`.

    `collectViewportEscapees(page)` runs the per-element sweep inside `page.evaluate` and returns an
    array of escapee descriptors, each carrying the tag name, the class string, and the measured
    `right` and `left` values. It walks every element, skips those computing `visibility: hidden` or
    `display: none`, skips intentionally off-canvas elements (the screen-reader-only utility and the
    far-left honeypot offset), skips zero-area boxes, and collects any element whose bounding-box
    right edge exceeds `window.innerWidth + 1` or whose left edge is below `-1`. The tolerance is
    exactly one CSS pixel for subpixel rounding, taken as a named exported constant with a comment
    citing why it exists — and there is no epsilon anywhere else, matching the raw-value comparison
    discipline the focus-contrast constants already state.

    `measureDocumentWidths(page, { neutraliseMask })` returns the document element's scroll width and
    client width. When `neutraliseMask` is true it first adds a stylesheet forcing horizontal overflow
    visible on the document root, the body and every descendant, and the returned record carries a
    `mode` field marking it as a modified-page measurement. Comment, at the function, that the
    unmodified reading is necessary but explicitly not sufficient — both top-level wrappers ship a
    horizontal-clipping utility that absorbs real overflow, so a run that reported only this reading
    would be a non-assertion wearing the costume of one — and that a modified-page reading must never
    be conflated with an unmodified one in the evidence.
