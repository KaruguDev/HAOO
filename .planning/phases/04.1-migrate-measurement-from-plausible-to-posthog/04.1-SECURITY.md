## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| npm registry → repository | Third-party packages (`posthog-js`, `@posthog/wizard`) enter build inputs and the published bundle | Executable code |
| built bundle → public internet | Every asset under `dist/assets` is world-readable | Application source, build-time constants |
| browser → PostHog ingestion | Visitor actions emitted as named events to `us.i.posthog.com` | Event name only (no person profile, no automatic capture) |
| browser → local storage | Client-side persistence surface the SDK could write to | Phase 3 engagement-context key only |
| owner workstation → PostHog Query API | Local report script issues an authenticated HogQL query | Personal API key (Query Read scope), aggregate counts |
| PostHog project settings → ingestion | Server-side enrichment the codebase cannot observe or assert | Geo-derived properties (owner-suppressed) |
