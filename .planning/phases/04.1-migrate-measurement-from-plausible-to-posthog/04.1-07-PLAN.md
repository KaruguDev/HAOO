<objective>
Re-point the owner report at PostHog without losing a single guarantee — and state, in the
report's own text, the two guarantees PostHog cannot supply.

The Plausible Stats API echoed the site id; the PostHog Query API echoes the query and the
compiled HogQL but not the project. That is a real weakening and it may not be dropped
silently. In exchange, the reporting timezone moves from a remote site setting into the
submitted SQL, which retires the timezone-mismatch failure mode entirely rather than porting
it — a strict improvement that must also be stated rather than quietly disappeared.

Everything else is preserved byte-for-byte: capability injection, the key in an
`Authorization` header only, the abort-before-write ordering, the exclusive temporary-sibling
reservation, and every one of `parseGoalCounts`' rejection rules.

Purpose: the owner sees the same four literal counts, from a different provider, with the
same refusals.
Output: a HogQL query path, an adapted row reader, a re-pointed credentialed CLI, and two
new sentences of honest provenance.
</objective>
