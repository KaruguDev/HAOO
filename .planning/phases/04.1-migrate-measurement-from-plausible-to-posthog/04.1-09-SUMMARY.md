## Decision recorded — deferred item D4

**Option A — static value import — was selected by the owner** at the Task 1
`checkpoint:decision` gate (`gate="blocking-human"`, returned to the coordinator and answered
`option-a`).

D4 had been open since `04.1-04` and was explicitly assigned to `04.1-08`, which neither made
the decision nor carried it forward. The one-way consequence is recorded rather than assumed:
the choice fixes the event-sink seam as **synchronous**. `initialize()` in
`src/measurement/index.ts:326` assigns `eventSink` inside the product page's mount effect and
the first `haoo_page_view` fires on the same tick, so Option B's provider-gated dynamic import
would have dropped that event unless this project kept an ordered emission buffer — and
`eventQueue`, `eventLog`, `emittedEvents`, `retryTimer`, `setTimeout` and `setInterval` are all
forbidden by name. Option B therefore cost an async facade **plus two widened privacy
prohibitions**, against Option A's recorded narrowings. Option A also matches the premise
`04.1-01` had already written into the `PROVIDER_INGESTION_HOST_SOURCE_FORBIDDEN` doc comment
("This project now imports the SDK instead…") — a premise that was false until this plan.

## Deviations from Plan

**1. [Rule 2 — Missing Critical] The vendor-identity marker and SDK version derived rather than restated**

- **Found during:** Task 2 (step 3, the companion assertion)
- **Issue:** The plan specified "a marker unique to the pinned SDK". A hardcoded literal would
  drift silently from `package.json` at the next version bump — the exact staleness this plan
  exists to remove elsewhere.
- **Fix:** `PINNED_SDK_VERSION` is read from `package.json` at test time, so a pin that changed
  without the emitted chunk changing fails.
- **Files modified:** `src/test/build-output.test.ts`
- **Verification:** Suite passes; the assertion names the version in its failure message.
- **Committed in:** `caf7957`

**2. [Rule 2 — Missing Critical] The provider-unset probe blanks the SELECTOR, not just the credentials**

- **Found during:** Task 2 (step 3, second replacement)
- **Issue:** The plan said to mirror the existing provider-selected probe's "blanked provider
  environment". Mirrored literally, that blanks the token and api host but would *inherit*
  `VITE_HAOO_MEASUREMENT_PROVIDER` from the shell. A developer shell exporting `posthog` — the
  shell an owner performing the `04.1-11` enablement has — would have produced a
  provider-*selected* build, and the case would have asserted the opposite of its own name while
  still passing.
- **Fix:** The probe sets `VITE_HAOO_MEASUREMENT_PROVIDER: ''` explicitly, with the reasoning
  recorded in-line.
- **Files modified:** `src/test/build-output.test.ts`
- **Verification:** Mutation probe 3 — setting it to `posthog` makes the case go red.
- **Committed in:** `caf7957`

**3. [Rule 2 — Missing Critical] The README gate's loaders-present branch requires the successor, not merely the disclaimer's absence**

- **Found during:** Task 2 (step 4)
- **Issue:** As written, the loaders-present branch asserted only `readmeDisclaimsDelivery ===
  false`. That branch had never been reachable before this plan. It would have passed on a README
  that simply **deleted** the section — turning a documented withdrawal into a silence, which is
  precisely the move this repository forbids.
- **Fix:** The branch now also requires the successor heading, the delivery-condition sentence
  verbatim, and that the README names each loading module path.
- **Files modified:** `src/test/build-output.test.ts`
- **Verification:** Mutation probes 5a and 5b — both directions go red.
- **Committed in:** `caf7957`

**4. [Rule 3 — Blocking] Two extra journey-level tests reached the real SDK initializer**

- **Found during:** Task 2 (step 5)
- **Issue:** The plan named `src/test/measurement.test.ts:1050-1070, 1155-1195, 1335-1350` as the
  cases to restate. Two of them (`refusalCauses`' empty-slot row and `leaves the journey
  unchanged when the provider global is absent`) drove an **empty scope** through the full
  facade. With the SDK bound, an empty scope now resolves the real module and would have called
  the **real `init`** — putting the suite on the network, violating the plan's own isolation
  prohibition (MEAS-07).
- **Fix:** Added `breakBoundInitializer()`, which replaces the bound module's `init` with a
  non-callable value (so the real initializer is structurally unreachable) and restores the
  original property descriptor in an `afterEach` — `vi.restoreAllMocks()` does not undo a
  `defineProperty`. Both cases keep their original empty scope and assert the successor refusal.
- **Files modified:** `src/test/measurement.test.ts`
- **Verification:** An instrumented probe wrapped the real `posthog.init` for a full
  `npx vitest run`: **0 invocations** across all 668 tests. Probe removed afterwards.
- **Committed in:** `caf7957`
