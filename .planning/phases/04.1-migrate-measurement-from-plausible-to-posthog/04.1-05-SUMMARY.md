- **D-04 gate 1 at full depth.** `fail-closed provider initialization` now carries one hostile case per locked key, and the key list is read off `POSTHOG_LOCKDOWN` rather than restated — 33 rows today, and a 34th the moment a key is added. Both that readback and the facade's single provider call are now guarded.

## Decisions Made

- **An unreadable ambient slot refuses at the adopted-versus-installed gate.** A slot whose read throws is an existing global this module cannot classify, and an unclassifiable global is foreign by definition. Refusing it at the scope gate would have named a gate that did not refuse.
- **Trimmed emptiness is the configuration gate.** A deployment variable set to a space is an unconfigured build. The vendor accepts a blank project key with a log line rather than a throw, so the repository has to refuse it.
- **The readback is wrapped.** It is the only code that reads the merged configuration key by key, and it reads it from inside the page's mount effect. See Deviations.
- **Path exhaustiveness is documented as a comment, never as an expected set.** The expected event-name set is derived from `HAOO_MEASUREMENT_EVENTS`, so an eleventh allowlisted name with no journey path fails.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing Critical] A hostile merged configuration could unmount the product page**

- **Found during:** Task 3 (`leaves the journey unchanged when the merged configuration reads back hostilely` — red on first run)
- **Issue:** `lockdownHolds` reads ~33 properties off the vendor's merged configuration, which is untrusted third-party data. A throwing getter anywhere in it threw straight out of `createPostHogEventSink`, out of `initialize()`, and out of the product page's mount effect — the exact Phase 4 gap-1 shape, on the enablement path this phase turns on for the first time. `readProperty` guarded the read *of* `config`; nothing guarded the reads *within* it.
- **Fix:** The readback call is wrapped; a throw is a refusal (`POSTHOG_REFUSAL.lockdown`), not an exception.
- **Files modified:** `src/measurement/posthog.ts`
- **Verification:** The test was red before the fix and green after; the whole journey now survives the hostile config with every `track()` returning true.
- **Committed in:** `82f6e10`

**2. [Rule 2 - Missing Critical] The facade's one provider call had no try/catch**

- **Found during:** Task 3
- **Issue:** `04-VERIFICATION.md` names this precise call in its key-link table — "`index.ts:322-324` is the one provider call in the file with no try/catch (gap 1)". The adapter is written never to throw, but that is a property of the adapter, not of the call site, and the cost of being wrong is the visitor's whole journey.
- **Fix:** Wrapped; a throw leaves `eventSink` undefined, which is the same inert state as an unconfigured build.
- **Files modified:** `src/measurement/index.ts`
- **Verification:** Removing the sibling guard in `track()` turns four tests red (isolation probe above), proving the surrounding isolation is asserted rather than assumed.
- **Committed in:** `82f6e10`

**3. [Rule 1 - Bug] A whitespace-only token or ingestion host reached `init`**

- **Found during:** Task 1
- **Issue:** The configuration gate tested `=== ''`. Task 1's `<behavior>` requires a whitespace token to refuse with no init attempted; it did not.
- **Fix:** The gate now trims before testing emptiness.
- **Files modified:** `src/measurement/posthog.ts`
- **Verification:** `name-only provider sink > returns no sink, and attempts no initialization, when %s` — 4 rows, each asserting `initializedToken()` is null.
- **Committed in:** `0fbfc6f`

**4. [Rule 1 - Bug] A throwing slot read named the wrong gate**

- **Found during:** Task 1
- **Issue:** Reading a hostile `scope.posthog` getter refused with `unreachable-global-scope`, which describes a page with no global scope at all — a materially different diagnosis for the owner reading the channel.
- **Fix:** Refuses with `foreign-provider-global` and a comment explaining why an unclassifiable global is foreign.
- **Files modified:** `src/measurement/posthog.ts`
