<objective>
Close the accept half of the trust decision. The refusal half is genuinely well built — six
hostile shapes, all passing — but the accept half grants full trust on the presence of one
callable property (`src/measurement/posthog.ts:167`).

`04.1-VERIFICATION.md` traced the consequence precisely: a client a third party puts on
`window` is adopted, handed the public project key and all ten first-party events, and can
echo back the configuration object it was given so the readback passes. Since commit
33deb5a the 33rd key is compared by identity, which closes the substituted-reducer half —
but the adoption itself remains, and `MeasurementDisclosure.tsx` names PostHog in the United
States as the sole processor of that data (D-10). That sentence is not true of an adopted
global.

04.1-09 supplies the precondition: a legitimate client now exists to bind to. This plan
removes adoption entirely. Two of gap 2's three `missing:` items are already closed by
33deb5a — this plan verifies them and proves them falsifiable rather than re-doing them, and
records that they were already closed so the next reader is not told this plan wrote them.

Purpose: the only client this adapter can ever initialize is one this repository chose.
Output: an occupied-slot refusal, the CR-02 regression that proves it, and a security
register that matches the code.
</objective>
