<objective>
Make the visitor-facing disclosure true again after the processor and its jurisdiction
changed.

D-08 moves measurement to PostHog Cloud US, so analytics data is now processed in the
United States. `MEAS-04` is a surface Phase 4 verified, and D-10 makes this a copy change
to that surface, not merely a configuration change — it must be re-verified. The disclosure
interface has no processor, region, or recipient member today; the existing processor
sentence names the form's email forwarder, not the analytics provider.

Research also surfaced an open question the owner must rule on: the payload that leaves the
page carries a per-page-load transport reference and the public project token. The Phase 3
sentence about bare names with no form answers or visitor properties attached remains true
as written, but whether that adequately covers an ephemeral transport reference for a
`MEAS-04` audience is a copy judgment, not a technical fact.

Purpose: keep the disclosure a true description of what actually leaves the page.
Output: a required interface member, owner-approved copy, a rendered group, and re-verification.
</objective>

  <context>
    This is a `MEAS-04` surface Phase 4 already verified, and Phase 3 set the precedent that
    visitor-facing copy is owner-approved byte-exact before implementation (the D-16 and C-1
    checkpoints). Two facts changed:

    1. **Jurisdiction.** Analytics data is now processed by PostHog in the United States
       (D-08). The disclosure has no member that can say so today, so this is new copy, not
       an edit.
    2. **What actually leaves the page.** The wire payload carries the public project token
       and a transport reference that is generated per page load, never written to browser
       storage, never reused across loads, and not joinable to a qualification submission.
       The existing Phase 3 sentence — that signals are sent as bare names with no form
       answers or visitor properties attached — is still literally true. Whether it
       *adequately covers* an ephemeral transport reference for this audience is a copy
       judgment. The Kenyan Data Protection Act 2019 framing this project already uses for
       the form's processor argues for naming recipients at the point of collection.
       Over-disclosure carries no risk here.

    Nothing in the disclosure may reflect the visitor's own runtime values back to them —
    that is a locked prohibition inherited from Phase 3 and restated in the Phase 4 UI-SPEC.
    So the copy describes the mechanism in fixed words; it never prints a live value.
  </context>
