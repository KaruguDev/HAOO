honestly rather than by widening a proven assertion.

commit — the shape 04.1-01 established when it withdrew the delivery-mechanism guarantee —
not weakened by silence. Clause B of Success Criterion 1 (D-01, full replacement) is
already met in substance; this plan closes clause A.

  <decision>
    Which loading strategy closes D4?

    **Option A — static value import from `src/measurement/posthog.ts` (RECOMMENDED).**
    The vendor chunk ships in every build, including a provider-unset one. Cost: two
    build-output invariants must be renarrowed with named successors, and the bundle scans
    must be partitioned so the identity scan stays a claim about this project rather than
    about the vendor's minified artifact.

    **Option B — provider-gated dynamic import.** The vendor chunk is emitted only for a
    selected build, so a provider-unset bundle stays byte-for-byte as clean as it is today.
    Cost: `createPostHogEventSink` and `initialize()` are synchronous, and the first
    `haoo_page_view` fires on the same tick as `initialize()`. A dynamic import resolves in
    a later microtask, so that event is dropped unless an emission queue exists — and
    `eventQueue`, `eventLog`, `emittedEvents`, `retryTimer`, `setTimeout` and `setInterval`
    are forbidden by name in `src/measurement/index.ts` by the `pins the local record and
    bare tracking call` case, while `eventQueue` and `clickstream` are forbidden across all
    production source by `MEASUREMENT_IDENTITY_SOURCE_FORBIDDEN`. Option B therefore costs
    an async measurement facade PLUS the widening of two privacy prohibitions, against
    Option A's two bundle-scope renarrowings.

    Recommendation: **Option A.** Beyond the cost comparison, the phase's own recorded
    reasoning already assumes it — the `PROVIDER_INGESTION_HOST_SOURCE_FORBIDDEN` doc
    comment written by 04.1-01 states "This project now imports the SDK instead, so the
    vendor's own default host string necessarily ships inside the vendor chunk."

    Why this is one-way: the choice fixes whether the event sink seam is synchronous. It is
    read by `resolveMeasurementProvider`, the `eventSink` seam, and 662 tests (D-02 already
    rates relocating that boundary `costly`). Reversing to Option B later means turning the
    facade async and re-opening the queue prohibitions this project deliberately closed.
  </decision>
