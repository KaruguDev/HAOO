<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL query -> campaign memory | Untrusted query values enter the page and must be rejected unless uniquely allowlisted and whole-value valid. |
| localStorage -> typed context | Same-origin mutable JSON is attacker-controlled input and must be parsed and validated wholesale. |
| product components -> measurement facade | Components may send only a closed event name; measurement failure cannot affect native actions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Information Disclosure | `track` API | high | mitigate | A one-argument literal union plus runtime guard provides no property or form-value channel; static bundle tests reject identity/clickstream seams. |
| T-03-02 | Tampering | campaign and stored JSON inputs | high | mitigate | Reject duplicates, unknown keys/versions, extra fields, malformed values, and expired records wholesale before use. |
| T-03-03 | Denial of Service | Web Storage/History/provider boundaries | medium | mitigate | Catch property access and every operation, then use bounded page memory or no-op without branching UI behavior. |
| T-03-04 | Elevation of Privilege | build-time provider selector | high | mitigate | Map a closed public selector to audited code; never evaluate or inject an arbitrary URL. |
| T-03-SC | Tampering | package installs | high | mitigate | No dependency is added; research's Package Legitimacy Audit explicitly selects installed/native APIs only. |
</threat_model>
