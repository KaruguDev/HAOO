## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Sticky lead column never engaged**
- **Found during:** Task 1 visual check. The column top read -636px while the section was in view.
- **Issue:** The root page wrapper's `overflow-x-hidden` computes `overflow-y: auto`, which made the wrapper the sticky scroll container. It never scrolls, so `position: sticky` had no effect.
- **Fix:** `overflow-x-hidden` became `overflow-x-clip` in `ProductPage.tsx`, with a comment. Clip still masks horizontal overflow without creating a scroll container. The e2e mask neutraliser (`overflow-x:visible !important`) and the `targets.ts` clipping detection treat `clip` the same as `hidden`, and the preview e2e suite passed. The e2e comments that name `overflow-x-hidden` were left as they are.
- **Files modified:** src/pages/ProductPage.tsx
- **Commit:** 1984871

**2. [Rule 1 - Bug] Journey step titles misaligned within a stepper row**
- **Found during:** Task 2 screenshot review (1440-s04). Titles 2-4 sat ~16px below title 1, which wraps onto two lines.
- **Fix:** Added `content-start` to each journey `li`, so its implicit rows do not stretch to the row height. Added a visual-check rule that fails when step title tops in one row differ by more than 1px. The spread now reads 0 at every width.
- **Files modified:** src/pages/ProductPage.tsx, visual-check script
- **Commit:** 886cc41

**3. [Rule 1 - Bug] Visual-check script fixes**
- Chromium reports boxes for content inside a closed `<details>`, so the form-order and target checks now skip it. Only the summary itself counts.
- The element screenshot now puts the section top at the viewport top, so the sticky column is captured at its unscrolled position.
- `navigator` was removed from the `/* global */` comment, where it tripped eslint `no-redeclare`. Lint failed once on this and passed on rerun.
- **Commits:** 1984871, 886cc41, 5539165

**4. [Constraint override] Preview server command**
- The plan said to spawn `npm run preview`. The script spawns `node node_modules/.bin/vite preview --port 4173 --strictPort` instead, per the orchestrator constraint, and stops it by child PID.

**5. [Orchestrator instruction] Tracer gate**
- The tracer ran as an autonomous gate. Its verify (unit suites, build, visual check, preview form-states e2e) was re-run and passed before expansion, rather than stopping at a human checkpoint. The orchestrator asked for sequential execution of all tasks, and the plan is `autonomous: true`.

**6. [Scope] Commit contents**
