<objective>
Make the HAOO funnel trustworthy. First, stop automated form traffic from inflating `haoo_qualify_submit`. Second, add a section-reach signal that does not depend on the unload-only `$pageleave`.

Purpose: PostHog project 589225 (last 30 days) shows that 5 of the 7 "submitting" visitors follow one automated pattern. `haoo_qualify_start` is followed 69 to 210 ms later by `haoo_qualify_submit`, then 1 or 2 more submits about 5 s apart. They present as ordinary Chrome, so the posthog-js bot filter keeps them. Only 4 `$pageleave` were recorded against 47 `$pageview`, so how far anyone reads the page is unknowable today. The owner needs a submit count that means "a plausible human sent the form once" and a reach count per key section.

Output:
- a closed set of four reach events, wired end to end (tracer)
- a gated submit signal

FormSubmit delivery is unchanged. The PostHog dashboard insights are NOT touched here; the orchestrator updates them afterwards.
</objective>
